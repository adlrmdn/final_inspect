# Quality Control System Rules & Mandates

This repository represents the **Chimera Quality Control (QC) System** (also branded as **Chimera QC Console**). 

### Core System Philosophy
*   This application is strictly a **Quality Control System (QCS)**.
*   **DO NOT** refer to this system as a Manufacturing Execution System (MES) or reference "MES Console" branding. All such naming is completely prohibited.
*   Keep the system scope 100% focused on offline quality inspections, dynamic template rendering, visual defect logging, yield estimation, and offline SQLite synchronization.

### System Brand Identifiers
*   **Product Name:** Chimera QC Console (or Chimera Quality Control System).
*   **AI Assistant Name:** **Kaizen** (Japanese term for "continuous improvement").
*   **Operational Scopes:** Fabric Quality Control & Packaging Quality Control.

---

*Abide by these rules in all future documentation, code refactorings, user interfaces, and assistant prompts.*
